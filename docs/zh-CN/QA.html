本轮检查报告

结论与范围

本轮对打包的两个真实 WebGL2 案例分别执行了桌面、移动视口、完整导览和缺失 WebGL 回退检查，130 项通过 / 130 项检查。这是交互和实现检查，不是“任意画作都能得到同等品质”的证明，也不是艺术还原度评分。

《夜间露天咖啡座》的引擎、场景、纹理、音乐、样式与恢复的原始源码逐文件哈希一致；当前入口仅补充语言及少量辅助文案。未改动的完整原始 HTML、源码与历史报告另存于 examples/cafe-terrace/archive/。

《呐喊》为本轮重新实现并检查的版本；旧版本只有图片留存。旧图片、旧 AI 宣传图均单独归档，未计为本轮检查证据。

案例 桌面 移动视口 完整导览 WebGL 回退

检查涵盖：WebGL2 与深度测试、5 个绘制批次、GL 错误标志；中文/英文入口和切换；实际相机位移、飞行升降、步行边界；六个地点；完整 28 / 32 秒导览结束和手动中断；音乐不在载入时自动播放、用户交互后 AudioContext 启动和关闭；界面隐藏/恢复；实际 PNG 下载；360×800 与 800×360 视口、摇杆与升降控制；WebGL2 缺失时的可读错误页；无未处理 JavaScript 错误和运行时外部请求。

执行方式与局限

使用 Linux、Chromium 144.0.7559.96、Playwright、Xvfb / SwiftShader。因当前浏览器的导航限制，测试通过 set_content 载入真实完整 HTML，并阻止全部网络请求；不是用户电脑上双击 file:// 或真实托管 URL 的端到端测试。源码的内联资源结构同时进行了静态检查。

没有实际测试 Safari、Firefox、真实 iPhone/Android、不同显卡或长时间运行。软件渲染环境的时间不作为硬件性能指标。音频已检查调度和开关，但没有真人听审。没有在真实 AI 客户端完成安装流程，也未对“任意上传图自动转换”进行泛化测试；本工具包本身不包含这样的推理模型。

构建、双语与素材

两种语言 Skill 的 YAML 已解析；初始化、带空格路径、异地构建、参考图原样复制、拒绝覆盖非空目录、拒绝错误参考格式均已执行。两套案例移到临时目录后重新构建，中英文 HTML 与交付文件逐字节一致。详见 qa/current/portability.json。

8 张新双语宣传图使用本轮实际 WebGL 帧，不含界面叠字，并保留可编辑 HTML。已检查页面宽度与底部内容位置，并查看横版和竖版成图。没有将字体文件打入包内。概念图中的历史文案不作为能力承诺，发布文案以本轮文档为准。

证据与复跑

每个案例的 qa/test-*.json 保存逐项结果；同目录保存桌面、中英文移动视口、反向/高处视角、完整导览和导出 PNG。qa/current/cafe-baseline-integrity.json 记录原始咖啡座的保留情况。

从压缩包根目录执行：

node scripts/build-all.mjs
node scripts/check-package.mjs
python tests/smoke.py --browser /path/to/chromium --case cafe-terrace --suite desktop

浏览器测试脚本需要自行安装 Python Playwright 和可用 Chromium；Linux 软件渲染环境可能还需 Xvfb。它们不属于网站运行依赖。当前包的静态验证结果记录在 qa/current/package-static.json；该记录不替代浏览器或视觉检查。
