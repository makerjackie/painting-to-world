# 入画 · Painting to World
## 把一幅画，变成一个可以走进去的世界。

**1.1 · 中英文完整创作包 · MakerJackie**

先打开 `START-HERE.html`。这是整个压缩包的离线导航，不是在线上传生成服务。

本包围绕成功的《夜间露天咖啡座》提炼可复用的方法与代码：分析画面、确定识别点、搭建真实三维空间、设计笔触材质和镜头、浏览器检查、源码交付。没有混入此前有问题的《星月夜》版本。

## 最快开始

直接打开两个案例目录里的 `index.html`（中文）或 `index.en.html`（英文）。进入后也可切换语言。页面中的三维场景、音频、纹理不依赖网络；点馆藏来源链接才需要联网。桌面浏览器需支持 WebGL2。手机系统可能只把 HTML 当文档预览，正式手机访问建议通过静态网站地址。

要创作新画作，**只选择一份语言版 Skill**：把对应 `painting-to-world` 整个目录交给能看图、读写文件并编写代码的 AI，连同参考画一起提供。不要只复制 `SKILL.md` 而遗漏代码底座。安装与完整提示词见使用指南。

```text
请使用 painting-to-world Skill，把我上传的画作做成真正可漫游的 3D 网站。
先分析原画构图与识别点，复用咖啡座的工程能力，但为这张画重新设计场景。
保留中英文、自动导览、自由探索、移动端控制和真实截图导出。
实际查看浏览器画面并修复，最后交付离线 HTML、完整源码与检查报告。
```

## 本地构建

在本包根目录执行（需要 Node.js 18+；不用 npm install）：

```bash
node scripts/build-all.mjs
node scripts/check-package.mjs
```

这会重新生成两个案例的中英文单文件 HTML。不是把新上传的画作自动变成三维模型。

## 版本说明

咖啡座沿用成功源码，保留场景、网格、材质与镜头；本轮仅补齐语言入口、加载/辅助标签、截图文案与可移植构建。原始网页和检查记录留在案例 `archive/` 中。

此前《呐喊》只有截图留存，没有找回对应源码。因此本包交付的是沿用咖啡座 WebGL 引擎重新实现的《呐喊》，不是冒充旧源码。旧截图只作历史记录，正式宣传图使用本轮实际运行画面。蒙克的原作与本项目创造的三维空间应分开看待。

Skill 是给 AI 的工作流和工程底座，不是独立图生三维模型。新画作需要逐图创作、检查和迭代；不承诺任意图片一次生成都达到相同效果，也不包含模型额度、托管服务或视频成片。完整边界见 `docs/zh-CN/PRODUCT.md` 和 `docs/zh-CN/QA.md`。
