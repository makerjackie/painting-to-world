## 实际验证的行为

- WebGL2 创建、着色器编译、几何上传、五次绘制和后处理均成功，交互前后 WebGL 错误标记均为 0。
- 桌面键盘移动、拖动环顾、步行/飞行切换、飞行升高、回到地面以及墙体/桌面碰撞规则通过。咖啡馆入口与空街道可走，墙体和桌心不可走。
- 六个目的地全部可切换；到访状态记录六个地点；返回首页、隐藏/恢复界面、中英文切换、说明与设置对话框均通过。
- 轻量模式实际重建为较低像素分辨率；减少动态模式不强制启动自动导览。
- **完整自动导览实际播放完成**，结束后进入自由飞行。该轮外部测得约 27.56 秒（从点击返回之后计时），不是仅调用“跳到结束”模拟完成。重播、Esc、拖动和移动打断均通过。
- 音频在进入之前未自动播放；用户点击后 AudioContext 进入 running 状态并实际调度音符；静音按钮生效。此处验证的是音频引擎，不代表真人耳听验收。
- 明信片功能通过实际按钮触发下载，得到真实 PNG：`qa/09-exported-postcard.png`，包含画框和署名，不包含交互界面。
- 手机尺寸测试覆盖 360×800，中英文顶栏均无重叠。触屏入口、摇杆、飞行按钮、升高按钮、可横向滚动的目的地栏可用；横屏 800×360 后渲染目标正确调整。
- 有触屏页面环境中使用了 tap 事件和浏览器指针输入验证控件；并非真实手机的多点触摸硬件测试。
- 强制无 WebGL2 时会显示清楚的错误说明，没有虚构的成功画面。
- 四组运行均没有未捕获 JavaScript 错误，没有运行时 HTTP 请求。外部博物馆资料链接未点击，属于按需外链。

## 视觉检查和修复

已查看真实渲染的桌面、手机、近景露台、室内、屋顶和星空截屏。修复和调整包括：增加雨篷坡度以突出黄蓝对比；缩小石板间过宽缝隙；调整桌旁镜头避免椅背挡住主视线；改用更远的屋顶视角；修复 360px 英文顶栏；区分导览时间与移动时间步长；使不可见的开场控件不再接收键盘焦点。

截图是实际程序渲染输出。视觉风格属于低多边形体量结合程序笔触，并非原画一比一重建或写实扫描。测试通过不等于美术已无需改进。

## 尚未验证 / 限制

1. 未在真机 iPhone、Android、Safari、Firefox、不同桌面显卡与企业受管浏览器中验证。未宣称跨设备帧率或 60 fps；SwiftShader 的速度不能当作硬件 GPU 性能结论。
2. 未实际验证本次环境下的 `file://` 导航、对外托管地址、全屏授权和所有移动浏览器的下载行为。完整网页没有导入、fetch 或外部资源，交付设计可离线运行；仍应在目标浏览器打开附件做最后确认。
3. 音乐的启动、音符调度和静音经过程序检查；未进行实际扬声器/耳机听音测试，亦未验证后台播放。页面隐藏时会停止播放音乐。
4. 飞行模式没有建筑碰撞；街区有界；天空不是天体模拟；没有人物寻路、多人在线、保存进度或 MP4 导出。
5. 没有进行屏幕阅读器专项、低视力对比度审计、长时间内存/电池测试或全设备兼容性认证。

## 复验

开发者已具备 Python Playwright、Pillow 和 Chromium 时，在相同 Linux 环境可运行：

```bash
xvfb-run -a python tests/verify.py desktop
xvfb-run -a python tests/verify.py mobile
xvfb-run -a python tests/verify.py tour
xvfb-run -a python tests/verify.py fallback
```

测试代码默认 `/usr/bin/chromium`，其他系统请将 `executable_path` 改为本机浏览器路径，并移除不适用的 Xvfb / Linux 参数。普通使用网页不需要安装这些测试工具。
