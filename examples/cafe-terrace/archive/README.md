# 夜色，尚未打烊。
## Café Terrace at Night · 画框之外 / Beyond the frame

为 MakerJackie 制作的、以梵高《夜间露天咖啡座》为灵感的可漫游三维网站。

不是将画面拖动的全景播放器：咖啡馆、桌椅、杯碟、街区和树木都由真正的三维几何组成。你可以改变位置、高度和观看方向。这里采用的是程序化绘画与风格化建模，而非扫描原作、摄影测量或神经辐射场。

## 先打开它

**直接用浏览器打开 `index.html` 即可，不需要安装依赖，不需要联网。**

单独交付的 `cafe-terrace.html` 与这里的 `index.html` 内容完全相同。需要浏览器支持 WebGL 2；浏览器或操作系统禁用硬件加速时，可能无法创建场景或运行较慢。没有三维支持时会显示清楚的错误页，而不是伪装成已加载。

点击「走进这幅画」开始约 28 秒的自动夜游，并开启配乐；也可以点击「我想自己走走」直接漫游。自动夜游从街角经过露台，逐渐升到屋顶和星空；咖啡馆室内可自由走入，或用地点按钮抵达。

没有账号、服务器、跟踪、CDN、外部模型、在线图片或 API 密钥。只有主动点击「关于这幅画」中的外部资料链接，才会访问网络。

## 操作

| 电脑 | 功能 |
| --- | --- |
| 鼠标拖动画面 | 环顾四周 |
| W A S D / 方向键 | 移动；Shift 加速 |
| 滚轮 | 前后移动 |
| 双击地面 | 尝试走到那里；遇墙或桌子会停止 |
| F | 步行 / 飞行 |
| Q / E | 飞行时下降 / 上升 |
| P | 导出当前视角的 PNG 明信片，不含界面 |
| H | 隐藏 / 恢复界面 |
| Esc | 停止自动夜游 |
| 顶部品牌按钮 | 回到开场 |

手机：左下摇杆移动，拖动画面改变视角；飞行时用右下的上下按钮调整高度。底部地点栏可以横向滑动。已适配手机尺寸，但不同手机的性能仍需实机确认。

六个地点：入画、一杯夜色、灯火里面、小巷深处、屋顶之间、星星之间。

右上角可以切换中文 / English，开关音乐、设置音量、调整颗粒和渲染精度、关闭自动运镜。页面会读取系统的「减少动态效果」偏好。轻量模式降低像素分辨率，不会减少几何数量。

### 修改后重新生成

电脑有 Node.js 18 或以上即可；不需要 `npm install`。

```bash
cd cafe-terrace-world
node scripts/build.mjs
```

直接重新打开 `index.html`。也可以使用本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。对外部署只需要上传生成的 `index.html` 到支持静态 HTML 的站点。没有服务端构建或 API 配置。

## 给下一位创作者 / 开发 AI

- **改标题、地点说明、引导语**：`src/app.js` 中的 `COPY`、`PLACES`、`TOUR_COPY`；开场 HTML 的初始文字也在 `src/index.template.html` 中。修改后运行构建脚本。
- **改六个视角**：`PLACES` 的 `p` 是相机位置，`t` 是注视点。三轴为 `[x, y, z]`，`y` 向上，街道向负 `z` 延伸。咖啡馆主墙约位于 `x = -5.5`，入口约位于 `z = 2`。
- **改自动导览**：`TOUR.p` 和 `TOUR.t` 是 Catmull–Rom 插值路径。时长在 `updateTour` 中是 28 秒；改变时长时也同步开场文案和测试。运动使用逐帧插值；自动导览时间与步行碰撞用的限幅时间步长分开。
- **扩展世界**：`world.js` 中的 `house`、`chair`、`table`、`person`、`tree` 都可复用。新增可碰撞物体时同时维护 `w.collider(...)` 或 `w.tables`。三维图形不会自动生成碰撞体。
- **改画风**：`textures.js` 的 `makePaint` / `makeSky` 生成纹理；`engine.js` 的 `sceneFS` / `postFS` 控制材质、暖光、雾、色彩、颗粒和边缘柔化。
- **改音乐**：`audio.js` 的 `chords`、`melody`、速度 84 以及音色包络可以编辑。现有音轨为 Web Audio 振荡器合成，不是 MiniMax 音频，也没有任何外部录音。
- **改署名**：页面底部署名在 HTML 模板中；导出的明信片署名在 `app.js` 的 `postcard()` 中。

为了保持真正可离线，新增纹理应继续用代码生成，或内嵌数据；不要无意加入在线 CDN、Google Fonts、外链纹理或运行时 fetch。

## 实现说明

使用原生 WebGL 2，而非远程加载 Three.js。场景按材质合批，当前版本约 269,329 个三角形、2,281 块独立石板，场景与后处理共 5 次绘制调用。纹理由种子随机数在本地生成；构建时不生成大型资源包。

表面采用笔触纹理和艺术化光照，并非完整的物理光照模型。阴影是简化的，人物不是写实角色，也没有角色寻路或游戏任务。目标是在一个有氛围的三维绘画街区里自由停留。

步行包含基础墙体和桌面碰撞；飞行模式允许穿过建筑，仅限制世界边界。街区有限，不是无限城市。天空是有绘画纹理的球体，不是天体模拟。网页有 PNG 明信片导出，没有内置 MP4 导出。

## 原画与想象的边界

原画为 Vincent van Gogh 的 *Café Terrace at Night / Terrace of a Café at Night*（1888），描绘阿尔勒的咖啡馆夜景，原作属于 Kröller-Müller Museum 馆藏。黄色灯火、蓝绿色夜色、圆桌、百叶窗和街道空间是本作品的起点。

室内、背街、屋顶、建筑尺度、立体人物、星空方位与配乐均为艺术化补充。这里**不是原画的三维扫描、数字修复、历史测绘或一比一复刻**，也没有宣称恢复了画框外真实存在的细节。

本项目不包含原画图片文件；原作资料链接见 `ATTRIBUTION.md` 和网站「关于这幅画」。
